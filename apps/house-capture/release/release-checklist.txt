3D MODEL ANYTHING — RELEASE CHECKLIST

Prepared locally; this is not an App Store submission.

Before upload:
- Set public HTTPS privacy and support URLs in project.yml and app-store-metadata.json.
- Add a real public support contact to the support page. Publish release/site on the chosen domain.
- Set copyright, pricing, reviewer contact and the final store name in App Store Connect.
- Confirm Apple Developer membership, current agreements, and distribution signing.
- Create an iOS app record for com.iggysosa.modelanything (this fork's bundle ID); disable Mac availability for this iOS-first release.
- Complete Apple's current age-rating and export-compliance questionnaires. The app uses no custom encryption; ITSAppUsesNonExemptEncryption is false.
- Confirm the final privacy answers. Make photoreal uploads a room's photos, LiDAR mesh and layout to a server the user configures; if you operate that server for users, this is data collection: update the privacy policy, store answers and the in-app wording first.
- Increment CURRENT_PROJECT_VERSION for each uploaded build.
- Run xcodegen, Release archive, release/validate.py <archive app path>, then Xcode Organizer Validate App.
- Export/upload through Xcode Organizer to App Store Connect and distribute in TestFlight.
- Review the local screenshot drafts (release/screenshots, ignored by Git) and capture the remaining real-device scanning screenshots. These drafts use personal room scans; choose which rooms to show publicly. Do not submit generated concept images.
- Complete physical-device acceptance below before requesting App Review.

Physical-device acceptance (not replaced by simulator self-tests):
[ ] First launch: grant, deny, revoke, and re-enable Camera; no empty capture opens on denial.
[ ] Complete a real room, finish the session, reopen it after force quit.
[ ] Background/lock during scanning: recording pauses; resume or save the partial room.
[ ] Tracking loss and recovery, including a poorly lit room and fast motion.
[ ] LiDAR iPad: scan, portrait layout, review and share-sheet presentation.
[ ] Non-LiDAR device: explanation, folder import, 3D review and sharing.
[ ] Long scan under thermal load; memory pressure; image/mesh preservation.
[ ] Low storage: start rejection below 500 MB, pause below 200 MB, finish/retry saves.
[ ] Large real export: AirDrop, cancel, retry; verify extracted files at the destination.
[ ] Room versions: switch, export, soft-delete, restore, permanent deletion.
[ ] VoiceOver, largest text size, long room names, empty library.
[ ] Privacy/support public URLs open, display correct contact, and match the app's behavior.
[ ] Make photoreal: configure server, upload over Wi-Fi and cellular, background mid-upload, job progress, failure message, View photoreal in the web view (orbit, pinch, layout).

Public release must wait until these manual checks and App Store validation are complete.
